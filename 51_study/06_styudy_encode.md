
# SC試験対策：URLエンコード・特殊文字一覧

## 1. URLエンコードとは

URLで使用する特殊文字などを `%XX` 形式で表現する方法。

`XX` は16進数の文字コードを表す。

例：
- `%0d` → CR（復帰）
- `%0a` → LF（改行）
- `%2f` → `/`（スラッシュ）

## 2. 覚えておきたいURLエンコード一覧

| エンコード | 元の文字 | 意味・用途 |
|---|---|---|
| `%0d` | CR | 復帰（キャリッジリターン） |
| `%0a` | LF | 改行（ラインフィード） |
| `%0d%0a` | CRLF | 改行コード |
| `%20` | 半角スペース | 空白 |
| `%2f` | `/` | パス区切り |
| `%5c` | `\` | バックスラッシュ |
| `%2e` | `.` | ドット |
| `%3f` | `?` | クエリ開始 |
| `%23` | `#` | フラグメント |
| `%25` | `%` | パーセント記号 |
| `%3d` | `=` | パラメータの区切り |
| `%26` | `&` | パラメータの連結 |
| `%3c` | `<` | HTMLタグの開始など |
| `%3e` | `>` | HTMLタグの終了など |
| `%22` | `"` | ダブルクォーテーション |
| `%27` | `'` | シングルクォーテーション |
| `%00` | NULL | NULL文字 |

## 3. 攻撃手法との関連

### HTTPヘッダーインジェクション

重要な文字列：`%0d%0a`

CRLF（復帰＋改行）を挿入し、HTTPヘッダーに意図しない情報を追加する攻撃。

例：
```text
%0d%0aSet-Cookie: admin=true
```

### ディレクトリトラバーサル

重要な文字列：`%2e%2e%2f`

デコードすると `../` になる。

上位ディレクトリに移動し、本来アクセスできないファイルへのアクセスを試みる攻撃。

### XSS（クロスサイトスクリプティング）

重要な文字：`%3c`、`%3e`

デコードすると `<`、`>` になる。

HTMLタグやスクリプトを不適切に処理させることで、悪意のあるJavaScriptを実行させる攻撃。

※URLエンコードされているだけでXSSが成立するわけではない。

### NULLバイト攻撃

重要な文字列：`%00`

NULL文字（0x00）を利用する攻撃。

プログラムや処理系によっては文字列の終端として扱われ、入力チェックと実際の処理に差が生じることがある。

### 二重エンコード

重要な文字列：`%252e`

1回デコード：`%2e`
2回デコード：`.`

複数回のデコード処理を悪用し、入力チェックを回避する攻撃に利用されることがある。

## 4. URLエンコード以外の特殊文字表記

HTMLエンティティによる表現。

| 表記 | 元の文字 |
|---|---|
| `&lt;` | `<` |
| `&gt;` | `>` |
| `&quot;` | `"` |
| `&amp;` | `&` |
| `&#39;` | `'` |

## 5. SC試験で優先して覚えるもの

| 優先度 | 表記 | 覚えること |
|---|---|---|
| 高 | `%0d%0a` | CRLF・HTTPヘッダーインジェクション |
| 高 | `%2e%2e%2f` | `../`・ディレクトリトラバーサル |
| 高 | `%3c%3e` | `<>`・XSS |
| 高 | `%00` | NULLバイト |
| 中 | `%252e` | 二重エンコード |
| 中 | `%2f` | `/`・パス区切り |

## 6. 暗記ポイント

- CRLF = CR（復帰）+ LF（改行）
- `%0d%0a` = CRLF
- `%2e%2e%2f` = `../`
- `%3c` = `<`
- `%3e` = `>`
- `%00` = NULL文字
- `%252e` = 二重エンコードの例

攻撃手法の問題文にエンコードされた文字列が出てきたら、まずデコードして意味を考える。
